# The Pomodoro Technique Version 1.1.0
A simple pomodoro timer built with JavaScript, React, and TailwindCSS. This webapp is built to help with productivity by focusing for 25 minutes and then a short 5 minute break.

## What's in this repo

| File / Folder | Purpose |
| --- | --- |
| `index.js` | Entry point for the React application |
| `index.css` | Global styles and Tailwind base styles |
| `App.js` | Root React component containing main app logic and timer |
| `tailwind.config.js` | Tailwind CSS configuration |
| `package.json` | Project metadata, scripts, and dependencies |
| `package-lock.json` | Auto-generated lock file for dependencies |
| `.gitignore` | Files and folders ignored by Git |
| `assets/` | Images, icons, and other static assets |
| `components/` | Reusable React components used throughout the app |

## How to use

## 1. Close this repo
```
git clone https://github.com/amendoza09/pomodoro-technique.git
cd pomdoro-technique
```

# 2. Install dependencies
Make sure you have Node.js install, then run:
```
npm install
```
this installs all modules required to run the app.

# 3. Run app locally
```
npm run start
```
This will open the timer in browser under localhost:3000 (if nothing is running on that port)
